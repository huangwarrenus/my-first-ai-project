# 光域 · 德国每日阳光照度

一个无需安装依赖的静态网页应用，用于查询德国各地未来 7 天的逐小时室外自然光照度。

交互式德国地图支持点击选点、悬停查看经纬度、方向键微调坐标，并显示德国当地太阳轨迹。

界面采用受 Enpal 官方网站启发的清洁能源视觉语言：深海军蓝、明亮黄色、白色圆角面板与清晰的大标题排版；产品名称与品牌仍为“光域”。

## 使用方法

直接双击 `index.html` 即可打开。若浏览器限制本地页面访问网络，可在此目录启动本地服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据与计算

- 天气与太阳辐照数据来自 Open-Meteo Forecast API。
- 水平照度以短波辐照度乘以约 120 lm/W 的日光光效估算。
- 接口不可用时，应用自动切换到离线晴空天文模型。
- 所有照度值仅作趋势参考，不替代专业照度计实测。
